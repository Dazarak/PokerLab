# PokerLab

Application Android native développée en **Kotlin**, permettant d'affronter des agents d'intelligence artificielle basés sur le **Reinforcement Learning (RL)** dans des parties de Texas Hold'em Poker.

## 💡 Concept

Contrairement aux architectures IA classiques dépendant de serveurs distants, **PokerLab** embarque ses algorithmes d'apprentissage directement sur l'appareil :

* **RL Tabulaire Local** : L'IA met à jour sa matrice de décision (Q-Learning) en temps réel après chaque main.
* **100 % Autonome** : Aucune dépendance réseau, aucun serveur backend, aucun coût d'infrastructure.
* **Exécution Native** : Moteur de jeu et logique RL développés intégralement en Kotlin.

## 🛠️ Stack Technique

* **Langage** : Kotlin
* **Plateforme** : Android
* **Algorithmes** : Tabular Reinforcement Learning (Q-Learning)
* **Build Tool** : Gradle
